# BZF Trainer

Lern-App für die Theorieprüfung (Prüfungsteil „Kenntnisse") zum BZF I und BZF II.

- Alle 261 Fragen aus dem Fragenkatalog der Bundesnetzagentur, gültig ab 01.05.2024
- **Grundlagen:** 13 Lektionen mit 81 Lernkarten, Karte für Karte durchblätterbar, mit Sprung zu den passenden Fragen
- **Lernen:** Lernrunden nach Thema mit Karteikasten-Prinzip (Leitner), Antworten in zufälliger Reihenfolge, Erklärung zu jeder Frage
- **Funk:** Praxis-Szenarien auf Deutsch und Englisch (Abflug, FIS, Kontrollzone, Notfall, Funkausfall), zum Auswählen oder Selbst-Formulieren
- **Prüfung:** Simulation mit einstellbarer Fragenzahl, Zeit und Bestehensgrenze
- **Katalog:** alle Fragen mit richtiger Antwort, durchsuchbar
- Fortschritt bleibt im Browser gespeichert und lässt sich per Code auf ein anderes Gerät übertragen

Läuft ohne Installation im Browser: `index.html` öffnen oder über GitHub Pages bereitstellen.

Verbindlich ist allein der von der Bundesnetzagentur herausgegebene Fragenkatalog in seiner aktuellen Fassung.
